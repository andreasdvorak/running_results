Coding Style

We want your work to be readable by others; therefore, we encourage you to note the following:

Please write code compatible with the Python version specified in the
Dockerfile and keep dependencies aligned with `requirements.txt`.

Use descriptive names for functions, classes, and variables. Clear naming is
preferred to redundant comments.

Expand unfamiliar acronyms where that improves readability.

Follow the Python naming conventions: `snake_case` for variables and
functions, `UPPER_CASE` for constants, and `PascalCase` for classes.

Before opening a pull request, run the test suite and the configured
pre-commit checks. Target the `develop` branch for ongoing development.
